# README images: shot list

Every image the README uses, what it should show, and its size. Deliver each
file with the exact name given; they go on the `readme-images` branch and the
README picks them up from there.

## For every image

- **Zen with Zia**, dark mode, **Sidebar and Top Toolbar** layout, macOS.
- **The same setup throughout:** one space, the same essentials and folders,
  the same wallpaper, so the images read as one product.
- **Real, recognisable sites** (YouTube, GitHub, Twitch, Reddit…), nothing
  personal: no email, account names, notifications or private tabs.
- **Retina captures, shown at half size:** export at the size given (that's
  the 2× size). Stills as **WebP** (or PNG for small crops), motion as **GIF
  under 5MB** or **MP4** (GitHub plays uploaded MP4s inline).
- **Loops:** short (3–6s), start and end on the same frame, no cursor
  jumping in from nowhere.
- Leave a little breathing room around crops; no drop shadows or device
  frames unless they're used on every image.
